# Notebooks

## [Random Processes](http://localhost:8888/lab/tree/notebooks/random_processes)

Collection of notebooks testing random process simulators and analysis programs for `FBM`, `ARIMA(p,d,q)`, `VAR(p)`, `ECM` and `VECM` models.

* [ARIMA](http://localhost:8888/lab/tree/notebooks/random_processes/arima)</br>
Analysis of ARIMA random processes.

* [Brownian Motion](http://localhost:8888/lab/tree/notebooks/random_processes/brownian_motion)</br>
Analysis of Brownian Motion and Fractional Brownian Motion.

* [ECM](http://localhost:8888/lab/tree/notebooks/random_processes/ecm)</br>
Analysis of Error Correction Model.

* [Ornstein Uhlenbeck Process](http://localhost:8888/lab/tree/notebooks/random_processes/brownian_motion)</br>
Analysis of Ornstein-Uhlenbeck process which is the basis of mean reversion models.

* [VAR](http://localhost:8888/lab/tree/notebooks/random_processes/var)</br>
Analysis of Vector Auto Regressive processes.

* [VECM](http://localhost:8888/lab/tree/notebooks/random_processes/vecm)</br>
Analysis of Vector Error Correction model.
